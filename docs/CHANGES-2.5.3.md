# CellCoal 2.5.3 — what changed

**Documentation only: the program and its output are identical to 2.5.2.**

- The manual is reorganized from top to bottom. Copy-number losses and gains are explained with the other mutations (chapter 5.2, with a table of the event types); the features that were added in earlier versions are in their own chapters (genealogy, starting genome, single-cell genomics, reads, arguments by group, summaries and sweeps, tests, Windows) instead of "what's new" sections; the numbering and the cross references are consistent; the version history is a short table that points to `docs/CHANGELOG.md`.
- New section 5.2.1 on how to start from a real chromosome (`--fasta`, `--region`, `--germline-vcf`) and which human genome assembly can be used.
- Examples of copy number and of reads in the quickstart.
