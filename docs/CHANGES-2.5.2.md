# CellCoal 2.5.2 — what changed

**Documentation only: the program and its output are identical to 2.5.1.**

- The README is rewritten: an overview of what CellCoal does now (genotypes, read counts and reads; chromosomes in blocks and real references; copy-number events), how to install it, examples, and the versions by theme.
- The manual (introduction, 4.2 and the notes on read counts) no longer says that CellCoal does not simulate individual reads: that is only true of the read-counts mode. The manual headings say the version that introduced each feature.
